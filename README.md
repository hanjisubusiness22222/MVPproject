## 1. 목적

기존 독서모임 연말모임에서는 연말모임 운영자가 네이버 카페 홍보, 구글폼 신청 취합, 카카오톡 반복 문의 응대, 엑셀 수기 명단 관리, 현장 자리배치, 명찰 제작, 사후 회비 정산 공유를 수작업으로 처리해야 했습니다. 그리고 참석 인원이 바뀔 때마다 참가자와 자리배치표를 일일이 다시 고쳐야 하는 불편함이 컸습니다.

이번 프로젝트는 연말모임 홍보와 안내부터 모임 신청자 확인과 자리배치, 정산 페이지까지 연말모임 행사 시 필요한 모든 서비스를 하나의 웹 페이지로 통합하여 기존에는 많은 인원이 필요한 연말모임 준비를 적은 인원이 진행할 수 있도록 하는 것이 목표이고 매년 있는 연말 모임마다 따로 형식을 만들지 않고 해당 웹페이지의 시스템을 유지하고 테마만 바꿔서 활용할 수 있도록 재사용성을 높이는 것이 목표입니다.

## 2. 사용자

- **핵심 사용자**: **연말모임 진행자**  
- **핵심 흐름과 완료 기준**:
  1. **홍보 및 안내, AI 챗봇 응대**
     - 흐름: 기존에는 네이버 카페와 오픈 카톡방으로 하던 홍보와 안내를 웹페이지로 진행하여 편의성과 접근성을 높이고 간단하고 반복되는 질문은 AI 챗봇이 24시간 대답할 수 있도록 함
     - 완료 기준: 진행자가 일일이 답변하지 않아도 참가자가 웹에서 안내를 확인하고 AI 챗봇을 통해 일정,장소,회비,단톡방 안내를 확인할 수 있게 함
  2. **참가 신청 및 입금 명단 관리**
     - 흐름: 참가자가 신청서에서 입력한 정보와 명찰을 웹페이지에서 확인할 수 있고 기존에는 일일이 만들던 명찰을 신청자가 신청만하면 자동으로 만들어지게 템플릿으로 만듦, 관리자 인증을 통해 민감한 개인정보를 보호하고 CSV 내보내기 기능 추가
     - 완료 기준: 신청 내역(학번, 성명, 연락처, 반뱃지, 아바타코드, 회비)이 대시보드에 자동 집계되고, 입금 확인 상태 전환 및 명단 CSV 백업이 완료
  3. **현장 자리배치·A4 학생증 일괄 인쇄 및 정산 공유 흐름**
     - 흐름: 진행자가 교실 자리배치에서 아바타가 반영된 좌석을 자동 셔플하고 행사장의 상황에 따라 유연하게 조배치를 할 수 있도록 조의 수를 조절 가능하도록 함 (3~8분단), 신청시 명찰도 연동하여 바로 인쇄할 수 있도록 함. 모임이 끝나고 정산 페이지에서 회비 사용내역을 확인할 수 있도록 함

## 4. 사용법

1. **초대장 (칠판)**: 공개 URL(https://mv-pproject.vercel.app/)에 접속해 디데이 카운트다운을 확인하고 칠판을 클릭해 가정통신문 요약과 네이버 지도 링크를 열람한 뒤 가정통신문 정식 열람하기를 누릅니다.
2. **안내 및 챗봇 상담**: 상단 탭에서 시간표, 드레스 코드, 장소 지도를 확인합니다. 모임에 궁금한 점이 있으면 우측 하단 챗봇 상담 버튼을 눌러 질문합니다. 관리자 페이지의 내용은 질의응답 불가능합니다.
3. **참가 신청 및 학생증 발급**: 상단 참가 신청 탭에서 공책 게임으로 명찰을 만든 뒤 이름, 휴대폰 번호, 참석 세션 선택 후 한마디를 입력하고 제출합니다. 완료 화면에서 학생증 PNG 저장, 계좌 복사, 공식 단톡방 입장을 이용할 수 있습니다.
4. **한 줄 방명록 작성**: 상단 방명록 탭에서 이름(최대 20자)과 응원 메시지(최대 200자)를 등록하고 데이터 베이스(Supabase)에 저장된 방명록을 확인합니다.
5. **운영진 관리**: 우측 하단 스위치의 관리자 버튼(비밀번호 0000)을 누르면 행정 대시보드에서 입금 상태 확인(더미 데이터), CSV 다운로드, 자리배치, 명찰인쇄, 정산 보고서를 확인할 수 있습니다.

## 5. 데이터 출처와 갱신일 (개인정보 및 보안 처리)

1. **데이터 출처**:
   - **참가 신청·정산 더미/시트 데이터**: 플래닛 연말모임 비공개 Google Sheets(`gid=1206999111` 및 영수증 탭) 연동 구조 및 과제 제출용 더미 데이터 + 브라우저 `localStorage(planet_rsvps)` 병합
   - **한 줄 방명록 데이터**: Supabase PostgreSQL 데이터베이스(`guestbook` 테이블) 실시간 API(`/api/guestbook`) 연동
   - **교무실 AI 챗봇**: Open HASA API(`gemma-4-31b`) 서버리스 프록시(`/api/chat`) 연동
2. **이용 조건**: 연말모임 참석 확인, 현장 좌석 배치, 학생증 명찰 인쇄, 회비 정산 목적으로만 한정하여 사용하며 외부 제3자에게 제공하지 않습니다.
3. **데이터 갱신일**: **2026-11-24** (페이지 진입 및 `[명단 새로고침]` 클릭 시 실시간 동기화)
4. **개인정보 보호 처리**:
   - 필수 입력값을 최소화(성명, 연락처, 참석 세션)하며, 관리자 대시보드 및 자리배치·명찰 인쇄 기능은 관리자 비밀번호(`SHA-256` 해시 검증, 테스트용 `0000`) 인증을 거친 운영진만 열람할 수 있도록 제한합니다.
   - AI 챗봇(`api/chat.js`)에는 관리자 페이지·비밀번호·접속 경로 질의를 차단하는 이중 보안 가드레일(`isAdminRestrictedQuery` + 시스템 프롬프트 제한)을 적용했습니다.
5. **보안 처리 (인증키 분리)**: `HASA_API_KEY`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `VITE_GOOGLE_SCRIPT_URL` 등 모든 민감한 인증키는 소스코드에 하드코딩하지 않고 **Vercel 환경변수**와 **GitHub Secrets**에만 보관하며 `.env.local`은 `.gitignore`로 차단했습니다.

## 6. 기술 구성

- **Frontend**: React 18, TypeScript, Vite 6, Tailwind CSS, Lucide Icons, `html-to-image` / `html2canvas`, `canvas-confetti`
- **Backend / Serverless**: Vercel Serverless Functions (`api/chat.js`, `api/guestbook.js`, `api/rsvp.js`), Google Apps Script (`google-apps-script.js`)
- **Database & AI**: Supabase (PostgreSQL REST API), Open HASA (`gemma-4-31b` Chat Completions API)
- **Testing & Deploy**: Node.js 내장 테스트 러너 (`node --test` 19개 단위 테스트), Vercel 자동 배포 (GitHub `main` 브랜치 연동)

## 8. 사용자 피드백과 반영

1. 사용자1: 모바일 환경에서 디자인이 깨진 부분이 있어 해당 부분을 반응형으로 디자인 반영 완료

2. 사용자2: 명찰 아바타 만들기 부분이 단순하고 어색한 부분이 있어서 아바타 선택 부분 확대 및 어색한 랜더링 부분 수정 완료

3. 사용자3: 연말 모임 장소를 네이버 지도와 연동해 바로 확인할 수 있었으면 좋겠고 회비 입금 계좌가 모임 신청 전에도 보였으면 좋겠다.
