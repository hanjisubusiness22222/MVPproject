## 1. 목적

기존 독서모임 연말모임에서는 연말모임 운영자가 네이버 카페 홍보, 구글폼 신청 취합, 카카오톡 반복 문의 응대, 엑셀 수기 명단 관리, 현장 자리배치, 명찰 제작, 사후 회비 정산 공유를 수작업으로 처리해야 했습니다. 그리고 참석 인원이 바뀔 때마다 참가자와 자리배치표를 일일이 다시 고쳐야 하는 불편함이 컸습니다.

이번 프로젝트는 연말모임 홍보와 안내부터 모임 신청자 확인과 자리배치, 정산 페이지까지 연말모임 행사 시 필요한 모든 서비스를 하나의 웹 페이지로 통합하여 기존에는 많은 인원이 필요한 연말모임 준비를 적은 인원이 진행할 수 있도록 하는 것이 목표이고 매년 있는 연말 모임마다 따로 형식을 만들지 않고 해당 웹페이지의 시스템을 유지하고 테마만 바꿔서 활용할 수 있도록 재사용성을 높이는 것이 목표입니다.

## 2. 사용자

- **핵심 사용자**: **연말모임 진행자**  
- **핵심 흐름과 완료 기준**:
  1. **홍보 및 안내, AI 챗봇 응대**
     - 흐름: 기존에는 네이버 카페와 오픈 카톡방으로 하던 홍보와 안내를 웹페이지로 진행하여 편의성과 접근성을 높이고 간단하고 반복되는 질문은 AI 챗봇이 24시간 대답할 수 있도록 함
     - 완료 기준: 진행자가 일일이 답변하지 않아도 참가자가 웹에서 안내를 확인하고 AI 챗봇을 통해 일정,장소,회비,단톡방 안내를 확인할 수 있게 함
  2. **참가 신청 및 입금 명단 관리**
     - 흐름: 참가자가 신청서에서 입력한 정보와 명찰을 웹페이지에서 확인할 수 있고 기존에는 일일이 만들던 명찰을 신청자가 신청만하면 자동으로 만들어지게 템플릿으로 만듦, 민감한 개인정보 같은 경우는 마스킹 처리하고 CSV 내보내기 기능 추가
     - 완료 기준: 신청 내역(학번, 성명, 연락처, 반뱃지, 아바타코드, 회비)이 대시보드에 자동 집계되고, 입금 확인 상태 전환 및 명단 CSV 백업이 완료
  3. **현장 자리배치·A4 학생증 일괄 인쇄 및 정산 공유 흐름**
     - 흐름: 진행자가 교실 자리배치에서 아바타가 반영된 좌석을 자동 셔플하고 행사장의 상황에 따라 유연하게 조배치를 할 수 있도록 조의 수를 조절 가능하도록 함 (3~8분단), 신청시 명찰도 연동하여 바로 인쇄할 수 있도록 함.
