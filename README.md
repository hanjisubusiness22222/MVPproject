## 1. 목적 (해결할 문제)

기존 독서모임 연말모임은 네이버 카페 홍보, 구글폼 신청, 카카오톡 공지, 엑셀 수기 명단 관리가 서로 흩어져 있어, 참가자 입장에서는 행사 안내·장소 지도·회비 입금·단톡방 입장·자리 확인을 한 번에 처리하기 어렵고, 운영진 입장에서도 신청자 취합과 현장 자리배치·명찰 인쇄·정산 공유에 많은 수작업 시간이 들었습니다.

본 프로젝트는 **홍보(티저 칠판) → 안내(가정통신문·일과표·룩북) → 참가 신청 및 크로키 학생증 발급 → 방명록/AI 챗봇 상담 → 관리자 자리배치·A4 명찰 인쇄·투명 정산**까지 하나의 웹 서비스로 통합하여 모임 참여와 운영의 번거로움을 줄이는 것을 목표로 합니다.

## 2. 사용자 (핵심 사용자 유형과 핵심 흐름)

- **핵심 사용자 한 유형**: **2026 플래닛 독서학교 연말모임 참가자(학우)** *(모임에 참여해 정보를 확인하고 신청·소통하는 일반 사용자 기준. 운영 관리를 위한 스태프 전용 대시보드는 보조 관리 흐름으로 연계)*
- **핵심 흐름 3가지와 완료 기준**:
  1. **행사 안내 확인 및 AI 교무실 상담 흐름**
     - *흐름*: 티저 칠판 열기 → `가정통신문` / `일과표 안내` / `드레스 코드 룩북` 탭 열람 → 네이버 지도(`지도보기 ↗`) 확인 → 궁금한 점은 우측 하단 `교무실 챗봇 상담`으로 질문
     - *완료 기준*: 일정·장소·회비(1부 3만원 / 2부 1만원 / 전체 4만원)를 확인하고 AI 챗봇에서 20초 이내에 답변을 수신함
  2. **크로키 아바타 학생증 생성 및 참가 신청 흐름**
     - *흐름*: `참가 신청(회신서)` 탭 진입 → 8단계 색연필 공책 아바타 제작 → 성함·연락처·참석 세션·한마디 입력 → `제출하기` 클릭
     - *완료 기준*: `2026-PLANET-XXXX` 학번과 학생증 PNG 저장 기능, 입금 계좌 및 공식 단톡방 입장 배너가 화면에 표시되고 관리자 명단/자리배치/인쇄판에 반영됨
  3. **한 줄 방명록 소통 및 운영 연동 흐름**
     - *흐름*: `한 줄 방명록` 탭 진입 → 이름과 응원 메시지 입력 후 등록 → Supabase DB 실시간 목록 확인 *(보조: 관리자 모드에서 자리배치 3~8분단 셔플, A4 학생증 일괄 인쇄, 정산 보고서 열람)*
     - *완료 기준*: 작성한 방명록이 새로고침 후에도 목록 최상단에 유지되며, 관리자 대시보드에서 신청자의 아바타·반뱃지·회비 상태가 정상 표시됨

## 4. 사용법

1. **초대장 접속 (티저 칠판)**: 공개 URL(https://mv-pproject.vercel.app/)에 접속해 디데이 카운트다운을 확인하고, 칠판을 클릭해 가정통신문 요약과 네이버 지도 링크를 열람한 뒤 `가정통신문 정식 열람하기`를 누릅니다.
2. **안내 및 챗봇 상담**: 상단 탭(`가정통신문`, `일과표 안내`, `드레스 코드 룩북`)에서 시간표·드레스 코드·장소 지도(`📍 지도보기 ↗`)를 확인합니다. 궁금한 점이 있으면 우측 하단 **`💬 교무실 챗봇 상담`** 버튼을 눌러 질문합니다. *(단, 관리자 페이지 정보 질의는 보안 정책상 차단됩니다.)*
3. **참가 신청 및 색연필 학생증 발급**: 상단 **`참가 신청(회신서)`** 탭에서 8단계 색연필 공책 게임(`✋ 멈춰!`)으로 나만의 아바타·반 뱃지·배경톤을 꾸민 뒤, 성함·휴대폰 번호·참석 세션(1부 3만원 / 2부 1만원 / 전체 4만원)·한마디를 입력하고 제출합니다. 완료 화면에서 **학생증 PNG 저장**, **계좌 복사**, **공식 단톡방 입장**을 바로 이용할 수 있습니다.
4. **한 줄 방명록 작성**: 상단 **`한 줄 방명록`** 탭에서 이름(1~20자)과 응원 메시지(1~200자)를 등록하고 Supabase에 저장된 실시간 방명록을 확인합니다.
5. **운영진 관리(보조 흐름)**: 우측 하단 스위처의 **`관리자`** 버튼을 누르면 더미 데이터와 방금 신청한 로컬 데이터(`localStorage`)가 통합된 행정 대시보드에서 입금 상태 토글, 12컬럼 마스킹 CSV 다운로드, **교실 자리배치(3~8분단 가변·아바타 연동)**, **교무실 A4 학생증 일괄 인쇄 조판기**, **정산 보고서 및 실물 영수증 모달**을 확인할 수 있습니다.

2. **이용 조건**: 연말모임 참석 확인, 현장 좌석 배치, 학생증 명찰 인쇄, 회비 정산 목적으로만 한정하여 사용하며 외부 제3자에게 제공하지 않습니다.
3. **데이터 갱신일**: **2026-11-24** (페이지 진입 및 `[명단 새로고침]` 클릭 시 실시간 동기화)
4. **개인정보 보호 처리**:
   - 필수 입력값을 최소화(성명, 연락처, 참석 세션)하며, 관리자 대시보드 및 CSV 내보내기 시 성명(`박*민`)과 연락처(`010-****-5678`)를 기본 마스킹합니다.
   - AI 챗봇(`api/chat.js`)에는 관리자 페이지·비밀번호·접속 경로 질의를 차단하는 이중 보안 가드레일(`isAdminRestrictedQuery` + 시스템 프롬프트 제한)을 적용했습니다.
5. **보안 처리 (인증키 분리)**: `HASA_API_KEY`, `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `VITE_GOOGLE_SCRIPT_URL` 등 모든 민감한 인증키는 소스코드에 하드코딩하지 않고 **Vercel 환경변수**와 **GitHub Secrets**에만 보관하며 `.env.local`은 `.gitignore`로 차단했습니다.

## 8. 사용자 피드백과 반영 (3명 이상 실사용자 피드백 기반)

실제 지인·예비 참가자 및 운영진 피드백을 받아 다음 5가지 개선 사항을 직접 코드에 반영했습니다.

1. **단톡방(카카오톡 오픈채팅) 연동 및 안내 문구 간결화** *(참가자 피드백)*
   - *의견*: 신청 완료 후 공지가 어디서 진행되는지 바로 알 수 있으면 좋겠고, 안내 문구가 너무 길다는 의견.
   - *반영*: 제출 완료 즉시 결과 카드에 카카오톡 오픈채팅 배너(`단톡방 입장하기 ↗` · `주소 복사`)가 나타나며 자동 스크롤되도록 구현했고, 설명 문구를 *"행사 세부 안내는 단톡방에서 진행됩니다."*로 간결화함.
2. **참가 비용(회비) 조정** *(참가자·운영진 피드백)*
   - *의견*: 1부·2부 참여 부담을 낮추기 위해 회비 체계(1부 3만원, 2부 1만원, 전체 4만원)로 조정 요청.
   - *반영*: 신청서 라디오 카드, 자동 회비 계산 스크립트, 가정통신문, 티저 페이지, 챗봇 지식 베이스 전역에 `30,000원 / 10,000원 / 40,000원` 일괄 반영.
3. **모임 장소 네이버 지도 링크 연동** *(참가자 피드백)*
   - *의견*: 텍스트로만 적힌 장소명 옆에 바로 길찾기를 열 수 있는 지도 링크가 필요하다는 의견.
   - *반영*: 가정통신문 개요 표와 티저 페이지에 1부(`공간나인 강남점` - `https://naver.me/5YFcRJ4m`) 및 2부(`포켓데이라운지` - `https://naver.me/FRoU25qb`) `📍 지도보기 ↗` 링크 추가.
4. **계좌 안내 문구 현실화 및 중복 UI 정리** *(참가자 피드백)*
   - *의견*: 계좌 안내의 기념품 문구를 실제 대관·식사 준비 안내로 고치고, 티저의 "컨셉 제안" 문구 및 신청서 상단 중복 컨트롤바·하단 중복 버튼을 정리해 달라는 의견.
   - *반영*: 계좌 안내 문구 수정, 티저 제목 정돈, 불필요한 상·하단 중복 UI 및 신청서 하단 공백 제거.
5. **관리자 대시보드 사용성 개선 & 챗봇 보안 강화** *(운영 스태프 피드백)*
   - *의견*: 관리자 화면에서 바로 `학생증 인쇄`로 이동할 수 있게 하고, 모바일에서도 가로 스크롤 없이 명단을 보고 싶으며, 일반 챗봇이 관리자 정보를 답하지 않았으면 좋겠다는 의견.
   - *반영*: 관리자 3단 퀵 카드(`자리배치 · 정산 보고서 · 학생증 인쇄`) 구축, 375px 모바일 카드 뷰 적용, 12컬럼 시트·CSV 스키마 통일, 챗봇 관리자 질의 차단 가드레일 구현.

## 9. 알려진 한계

1. **실물 영수증 이미지 업로드 미지원**: 현재 정산 보고서의 영수증 상세 모달은 시트·더미 데이터 기반의 전자 전표 UI로 제공되며, 실제 영수증 사진 파일(JPG/PDF)을 직접 업로드·미리보기하는 기능은 추후 스토리지 연동으로 보완할 예정입니다.
2. **오프라인/브라우저 로컬 캐시 의존 구간**: 과제 데모 안전성을 위해 개인정보가 포함된 실제 구글 시트 연동 대신 마스킹 더미 데이터와 브라우저 `localStorage`를 병행하므로, 다른 기기에서 신청한 내역이 즉시 공유되려면 실제 Apps Script 서버 URL 연결이 필요합니다.

- **AI 도움을 받은 부분**:
  - React/TypeScript 컴포넌트 스캐폴딩, Vercel Serverless API(`/api/chat`, `/api/guestbook`) 및 `node --test` 단위 테스트 구조 작성
  - 8단계 색연필 크로키 아바타 엔진의 공용 유틸 분리, A4 인쇄 조판 레이아웃 및 375px 모바일 반응형 CSS 구현 보조

  - 실사용자 피드백 수집 및 우선순위 결정(단톡방 연동, 회비 3만/1만/4만 조정, 네이버 지도 링크, 안내 문구 개선, 불필요한 중복 UI 및 공백 제거 요청)
  - 사용성과 디자인 검수 및 수정(아바타 헤어스타일 1·3·4번 윗머리 볼륨 보완 및 3번 목 부분 검은색 채우기 오류 수정, 복장 레이어 순서 조정, `'용의복장'`을 `'드레스 코드'`로 문구 변경)
  - 실제 행사 운영 파이프라인(티저 → 가정통신문 → 학생증 발급 → 자리배치·인쇄·정산)과 챗봇 보안 요구사항(관리자 정보 비공개) 정의 및 실배포 사이트 직접 테스트

## 11. 회고

한 학기 동안 "우리가 실제로 쓸 수 있는 연말모임 서비스"를 목표로 프로젝트를 진행하면서, 처음에는 단순히 예쁜 초대장 페이지를 만드는 것에서 출발했지만 **실제 사용자 피드백을 받고 운영 흐름을 고민할수록 서비스가 완전히 달라진다**는 것을 크게 배웠습니다.

특히 과제 제출용으로 시작한 버전에 **AI 교무실 챗봇과 Supabase 실시간 방명록**을 붙이면서 서버리스 API와 환경변수 보안, 타임아웃·경계값 예외 처리의 중요성을 직접 체감했고, 동시에 실사용 버전에서 얻은 피드백(단톡방 즉시 연결, 지도 링크, 아바타 연동 자리배치, A4 학생증 인쇄)을 다시 본 프로젝트로 통합하면서 **"기술 구현"과 "실제 사용자 경험"을 모두 놓치지 않는 설계 감각**을 기를 수 있었습니다. AI의 도움을 받아 빠르게 프로토타입을 만들더라도, 최종 화면의 여백·모바일 가로 넘침·키보드 접근성·보안 가드레일처럼 디테일을 끝까지 확인하고 다듬는 역할은 결국 개발자 본인의 몫이라는 점을 깊이 느낀 한 학기였습니다.
